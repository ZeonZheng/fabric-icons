## How to use

1. For a **ready-to-use draw.io library**, open [the original XML folder](Microsoft%20Fabric%20%26%20Azure%20Icon%20Pack/xml/) and select the matching library (Fabric Artifacts, Datasources, Core, Black, Azure Core, etc.).
2. Download the `.xml` and import it in diagrams.net using **File → Open Library from → Device**. The original upstream README also includes a multi-library auto-import URL.
3. For **PowerPoint or architecture slides**, browse the original [SVG folder](Microsoft%20Fabric%20%26%20Azure%20Icon%20Pack/svg/), with named resources and category folders.
4. To start from an example, open the [diagram template](Microsoft%20Fabric%20%26%20Azure%20Icon%20Pack/template/) or [original README](Microsoft%20Fabric%20%26%20Azure%20Icon%20Pack/README.md).
